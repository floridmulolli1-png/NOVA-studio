Om varumärket

Skandinavisk stillhet, exklusiv känsla.

Aurelia Objects föddes ur idén att belysning inte bara ska lysa upp ett rum — den ska forma det. Vi arbetar med varma material, dämpade kulörer och ett fåtal noga utvalda former, så att varje lampa får ta plats utan att skrika efter uppmärksamhet.

Varje objekt är designat för att åldras vackert: mässing som patinerar, linne som mjuknar, sten som får en djupare ton med tiden.
